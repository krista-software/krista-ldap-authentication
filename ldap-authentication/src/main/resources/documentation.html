Ldap Authentication Extension Documentation

This is an authentication extension for Open LDAP protocol.
This extension supports only 'Simple' authentication method with 'user/password' type of authentication operation.
Authenticated access is requested by providing a valid name and password.
After successful authentication from LDAP server extension will fetch user's profile with matching email address and phone number properties.
If LDAP user's entry doesn't have email address property this authentication extension will throw related errors as for
Krista platform 'Email' property is a required field.
NOTE:This extension is not taking care of any ldap roles. All ldap users are mapped to 'Default Role' defined in invoker parameters.

Ldap Server URL

An LDAP URL is a string that can be used to encapsulate the address and port of a directory server,
the DN of an entry within that server, or the criteria for performing a search within that server.
Example: ldap://myldap.example.com

Base DN

This property define base distinguished name (DN) for LDAP server.
All ldap search requests include the base DN element and the wholeSubtree scope (often referred to as “sub”) indicates
that the entry specified as the search base DN and all entries below it (to any depth) should be considered.

Bind DN

This property defines the admin bindDN DN credential you are using to authenticate against an LDAP.
In other words when you specify a bindDN you are using that object security access to go through the LDAP tree

Bind DN Password

Bind DN password to authenticate and access LDAP tree.

Default Role

The default role assigned to all LDAP user's if not present in workspace. The default value is 'Krista Client User'

Email Property

Name of the email property which can be mapped with ldap user's email address. This is a required field.
If not provided default value will be 'mail'.

Phone Property

Name of the telephone number property which can be mapped with ldap user's phone number. This is a optional field.
If not provided default value will be 'telephoneNumber'.
